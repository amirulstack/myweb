TRANSITVOICE — PROJECT BASED ON WEB TECHNOLOGIES UNITS 1 TO 4

FILES
- index.html : HTML structure, semantic elements, form and table
- style.css  : CSS styling, layouts, responsive design and animation
- script.js  : JavaScript validation, report handling and dashboard
- README.txt : this guide

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (or open index.html in a browser).
5. Submit a sample report, copy its report ID, track it and update its status in the dashboard.

SYLLABUS MAPPING

UNIT 1 — HTML FUNDAMENTALS
- HTML5 document structure, metadata, title, description and keywords
- Headings, paragraphs, links, lists, images/graphics and SVG
- HTML5 audio element example (add your own sample-audio.mp3 to use it)
- Hyperlinks and best practices such as alt/accessible descriptions and semantic structure

UNIT 2 — SEMANTIC HTML AND FORMS
- header, nav, main, section, article, aside, footer, form, fieldset and legend
- Labels, text/email/date/file inputs, select, textarea, checkbox and buttons
- required, minlength, maxlength, type=email and browser form validation
- Accessible names, focus styles, status announcements and responsive content
- Data table with caption, thead, tbody and column headers

UNIT 3 — CASCADING STYLE SHEETS
- External stylesheet, element/class/attribute selectors
- CSS variables, colors, typography, units, padding, margin and box model
- Flexbox, CSS Grid, positioning, pseudo-classes and pseudo-elements
- Form styling, responsive media queries, transitions and keyframe animations

UNIT 4 — JAVASCRIPT FUNDAMENTALS
- let, const, strings, numbers, booleans, objects and arrays
- Operators, template strings, string methods and number conversion
- if/else conditions, functions, parameters, return values and local scope
- Array methods: forEach, filter, reduce, find, map, unshift
- Object creation and property updates
- DOM selection, events, validation, Local Storage and dynamic table updates

IMPORTANT LIMITATIONS
This is a frontend educational prototype. Reports are stored in the current browser using Local Storage. They are not shared with another computer and there is no real server, database, authentication, email/SMS service or transport-authority connection. The attachment filename is recorded; the actual image is not uploaded. The optional audio control needs your own sample-audio.mp3 file.
